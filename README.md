## 🌐 GitHub Pages

1. Crie um repositório chamado `astroflash`.
2. Envie os arquivos mantendo `index.html` na raiz.
3. Vá em **Settings → Pages**.
4. Selecione **Deploy from a branch**.
5. Escolha `main` e `/(root)`.
6. Salve e aguarde a publicação.

## 📊 Fluxograma

A atividade complementar apresenta a ordenação de 10 números em uma matriz:

1. Digitar 10 números e armazenar na matriz.
2. Ler a matriz e percorrer os elementos.
3. Comparar o número atual com o próximo.
4. Se o atual for maior, trocar os dois.
5. Continuar até a matriz estar em ordem.
6. Mostrar a lista ordenada.

A apresentação editável está em `docs/`.
